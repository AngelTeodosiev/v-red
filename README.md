# V-red Atelier (démo)

Application web progressive (PWA) de démonstration pour l’atelier V-red : bons de travail, chrono des mécaniciens, pièces, factures et tableau de bord du gérant. Interface en français et en anglais.

Toutes les données sont des exemples et restent dans le navigateur de chaque appareil.

Mots de passe de démonstration : mécaniciens `1234`, réception `accueil`, gérant `gerant`, commis `commis`.

Hébergement : GitHub Pages (branche `main`, dossier racine).
